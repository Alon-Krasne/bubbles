# Magic House Bedroom Prototype

Standalone first-room vertical slice for the single-player bilingual Magic House game.

Run the dev server and open:

`http://127.0.0.1:5173/prototype/magic-house.html`

The production launcher and gameplay files are intentionally unchanged. The prototype demonstrates six cumulative room-building requests, English/Hebrew profiles, tap and drag placement, graduated help, non-punitive feedback, completion stars, and pre-rendered Google TTS instructions.

The committed WAV files are generated by Gemini 3.1 Flash TTS Preview. To regenerate all English and Hebrew request recordings:

```bash
GEMINI_API_KEY=... npm run generate:magic-house-tts
```
