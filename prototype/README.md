# Benchmark 0: Unified World Map

This standalone prototype establishes the visual and interaction direction for the future single-player educational game. It does not replace or modify the production screens.

Run the repository dev server and open:

`http://127.0.0.1:5173/prototype/world-map.html`

## Included interactions

- Mixed Memory Garden, Listening Shop, and Word Bubbles stages on one route
- Independent stars, current stage, learning language, and character for Lotem and Tom
- Tap-driven stage details rather than permanent labels on every node
- Sound and settings controls
- Simulated completion flow: celebration, star update, unlock, character movement, and next-stage focus

## Review viewports

- 1440 x 900
- 1024 x 768

The production integration belongs to Benchmark 1 after this visual direction is approved.
