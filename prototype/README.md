# Educational Game Prototypes

The prototype directory contains the mixed-game trail and its playable vertical slices.

## Unified World Map

Open `http://127.0.0.1:5173/prototype/world-map.html` after starting the dev server.

The map mixes Memory Garden, Listening Shop, Word Bubbles, and Magic House stages. It demonstrates independent profile progress, stars, stage details, unlocks, and character movement.

## Magic House

Open `http://127.0.0.1:5173/prototype/magic-house.html` to test the bedroom directly.

The room contains six cumulative English/Hebrew placement requests, profile-aware Google TTS, tap and pointer-drag placement, graduated help, non-punitive feedback, success toasts, and completion stars.

Pointer dragging uses one gesture path across mouse and touch. Failed drops always remove the drag ghost and return the tray object to rest. Drop zones and final object positions share the calibrated `ROOM_MAP` in `magic-house.js`, and only destinations required by the current sentence are mounted as hitboxes.

The committed WAV files are generated by Gemini 3.1 Flash TTS Preview. To regenerate all English and Hebrew request recordings:

```bash
GEMINI_API_KEY=... npm run generate:magic-house-tts
```
